# Data policy

This directory separates versioned inputs from generated artifacts.

## Versioned

- `sources/`: small source datasets used to build the search indexes.
- `knowledge_base/`: compact processed knowledge used by the application.
- `index/` and `indexes/`: prebuilt indexes required by the current interfaces.
- `metrics_report.json`: evaluation output kept for comparison.

## Local only

- `blogs/`: downloaded HTML, scrape results, URL validation output, and cleaned
  intermediate articles. These files are generated by the refresh pipeline and
  can be very large.
- `../logs/`: queries, responses, and feedback. These may contain user data and
  must not be committed.

Run the complete refresh from the repository root:

```bash
python src/run_daily_pipeline.py
```

Preview it without downloading or processing data:

```bash
python src/run_daily_pipeline.py --dry-run
```
